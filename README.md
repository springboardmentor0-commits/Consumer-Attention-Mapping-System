# Consumer Attention Mapping System (CAMS)

AI-powered retail intelligence platform using computer vision to track
shopper attention, product engagement, and in-store behavior.

## Stack
- **Backend**: Python 3.11, FastAPI, PostgreSQL, MongoDB, Redis, Kafka
- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **AI/ML**: YOLOv8, MediaPipe, DeepSORT, OpenCV, PyTorch
